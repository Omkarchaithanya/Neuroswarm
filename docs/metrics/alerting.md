# Alerting Guide

Rules generated by `neuroswarm_arm.metrics.alerts` → `ops/prometheus/rules/rmf-alerts.yml`.

Recording rules → `ops/prometheus/rules/rmf-recording.yml`.

Wired from `ops/prometheus.yml` via `rule_files`.

## Alert catalogue

| Alert | Intent |
|-------|--------|
| NexusHighLatency | P95 request latency |
| NexusPlannerFailure | Planner / admission failures |
| NexusBackendFailure | Routing / request errors |
| NexusBudgetExhaustion | Budget nearly empty |
| NexusMemoryPressure | RSS pressure |
| NexusKVCachePressure | Low reuse + evictions |
| NexusWorkerSaturation | HAOE util > 0.9 |
| NexusHighQueueDepth | Scheduler / admission queues |
| NexusSpeculativeFailure | Spec reject ratio |
| NexusStreamingFailure | Streaming errors |
| NexusPlannerPredictionError | Planner error |
| NexusEnergySpike | Power vs hourly baseline |
| NexusCPUSaturation | CPU > 0.9 |

## Regenerate

```bash
python -c "from neuroswarm_arm.metrics.alerts import write_alert_rules; write_alert_rules('ops/prometheus/rules/rmf-alerts.yml')"
python -c "from neuroswarm_arm.metrics.recording_rules import write_recording_rules; write_recording_rules('ops/prometheus/rules/rmf-recording.yml')"
```
